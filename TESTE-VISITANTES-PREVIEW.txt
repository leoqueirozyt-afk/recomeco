PASSO A PASSO - TESTAR A ÁREA DE VISITANTES EM PREVIEW
=====================================================

FERRAMENTAS NECESSÁRIAS:
- Git / GitHub CLI
- Conta na Vercel
- Projeto Recomeço no GitHub

================================================================================
PASSO 1 - CRIAR BRANCH DE TESTE
================================================================================

1.1 - Abra o terminal na pasta do projeto:

    cd "C:\Users\Raptor\Pictures\RECOMEÇO"

1.2 - Crie uma nova branch:

    git checkout -b feature/visitantes-preview

1.3 - Adicione as mudanças e commite:

    git add .
    git commit -m "feat: área de visitantes com integração Supabase"

================================================================================
PASSO 2 - FAZER DEPLOY DA BRANCH NA VERCEL (PREVIEW)
================================================================================

2.1 - Faça push da branch:

    git push -u origin feature/visitantes-preview

2.2 - No GitHub, abra o repositório do Recomeço:
    https://github.com/anomalyco/recomeco

2.3 - Você verá um banner roxo "Visitantes-preview had recent pushes"
    Clique no botão verde "Compare & pull request"

2.4 - Na página do Pull Request:
    - Mude a base para main (se não estiver)
    - Adicione um título: "feat: área de visitantes"
    - Clique em "Create pull request"

2.5 - O GitHub vai mostrar o status checks da Vercel.
    Aguarde o deploy da PREVIEW URL terminar.
    Você verá um comentário da Vercel com a URL do preview:
    "Deploy Preview for [url]"
    EXEMPLO: https://recomeco-git-feature-visitantes-preview.vercel.app

    COPIE ESSA URL - ela será o frontend de teste.

================================================================================
PASSO 3 - EXECUTAR SQL NO SUPABASE (AMBIENTE DE TESTE)
================================================================================

3.1 - Acesse o Supabase:
    https://supabase.com/dashboard

3.2 - Selecione o projeto Recomeço

3.3 - Vá em "SQL Editor" no menu lateral

3.4 - Copie e cole TODO o conteúdo do arquivo supabase-schema.sql
    (está em: "C:\Users\Raptor\Pictures\RECOMEÇO\supabase-schema.sql")

3.5 - Clique em "Run" para executar

3.6 - Verifique se apareceu "Success" e a tabela "visitors" foi criada.
    Vá em "Table Editor" no menu lateral e confirme que "visitors" aparece.

================================================================================
PASSO 4 - CONFIGURAR VARIÁVEIS DE AMBIENTE NO VERCEL (PREVIEW)
================================================================================

4.1 - Acesse o dashboard da Vercel:
    https://vercel.com/anomalyco/recomeco

4.2 - Vá em "Settings" → "Environment Variables"

4.3 - Adicione as mesmas variáveis que você tem na Vercel de produção:
    (Se já estiverem lá, não precisa adicionar de novo)

    SUPABASE_URL        = (sua URL do Supabase)
    SUPABASE_ANON_KEY  = (sua chave anon pública)
    SUPABASE_SERVICE_ROLE_KEY = (sua chave de serviço - cuidado, não expor no frontend)
    SUPABASE_JWT_SECRET = (secret do JWT)
    JWT_SECRET          = (mesmo valor que SUPABASE_JWT_SECRET)
    FRONTEND_URL        = (a URL do preview, ex: https://recomeco-git-feature-visitantes-preview.vercel.app)

4.4 - IMPORTANTE: Na seção "Environments", selecione "Preview"
    e adicione FRONTEND_URL com a URL do preview.

4.5 - Salve e vá em "Deployments"

4.6 - Encontre o deployment mais recente da branch "feature/visitantes-preview"
    Clique nos "..." → "Redeploy"
    Isso garante que as novas variáveis de ambiente sejam aplicadas.

================================================================================
PASSO 5 - ATUALIZAR O FRONTEND PARA APONTAR PARA A API DE PREVIEW
================================================================================

5.1 - No repositório GitHub, edite o arquivo:
    client/.env (ou crie se não existir)

5.2 - Adicione:
    VITE_API_URL = (URL do preview da API Vercel)

    Exemplo:
    VITE_API_URL = https://recomeco-git-feature-visitantes-preview.vercel.app

5.3 - Commit e push:
    git add .
    git commit -m "chore: api url para preview"
    git push

5.4 - Aguarde o novo deploy do preview terminar.

================================================================================
PASSO 6 - FAZER OS TESTES
================================================================================

Acesse a URL do preview:
https://recomeco-git-feature-visitantes-preview.vercel.app

FAÇA LOGIN com suas credenciais.

6.1 - TESTAR CADASTRO DE VISITANTE:
   - Clique em "Visitantes" no menu lateral
   - Clique em "+ Novo Visitante"
   - Preencha:
     * Data da Visita: 10/05/2026
     * Nome: João Teste
     * Sobrenome: Silva
     * WhatsApp: (11) 99999-9999
     * Observações: Veio no culto de domingo
   - Clique em "Cadastrar"
   - Confirme que o visitante aparece na lista

6.2 - TESTAR EDIÇÃO:
   - Na lista de visitantes, clique em "Editar"
   - Altere o nome para "João Atualizado"
   - Clique em "Atualizar"
   - Confirme que a alteração aparece na lista

6.3 - TESTAR EXCLUSÃO:
   - Na lista, clique em "Excluir"
   - Confirme a exclusão
   - O visitante deve sumir da lista

6.4 - TESTAR ENVIO PARA RECOMEÇO:
   - Cadastre um novo visitante
   - Na lista, clique em "Enviar p/ Recomeço"
   - Confirme a mensagem de confirmação
   - Deve aparecer: "Visitante enviado para o Recomeço com sucesso."
   - O status deve mudar para "Enviado para Recomeço"
   - O botão "Enviar p/ Recomeço" não deve mais aparecer
   - Vá em "Pessoas" no menu e confirme que o visitante foi criado lá

6.5 - TESTAR DASHBOARD:
   - Vá em "Dashboard"
   - Verifique se os 4 cards novos aparecem:
     * Total Visitantes
     * Visitantes Mês
     * Não Enviados
     * Enviados p/ Recomeço

6.6 - TESTAR BACKUP:
   - Vá em "Backup"
   - Clique em "CSV Visitantes"
   - Baixe o arquivo e abra no Excel para confirmar os dados
   - Clique em "Excel Visitantes"
   - Confirme que tem 2 abas: "Pessoas" e "Visitantes"

6.7 - TESTAR WHATSAPP:
   - Cadastre visitante com WhatsApp
   - Clique no botão 💬 ao lado do nome
   - Confirme que abre o WhatsApp com o número correto

================================================================================
PASSO 7 - SE TUDO ESTIVER OK, FAZER MERGE PARA PRODUÇÃO
================================================================================

7.1 - No GitHub, vá em:
    https://github.com/anomalyco/recomeco/pulls

7.2 - Encontre o PR "feat: área de visitantes"

7.3 - Se todos os testes passaram:
    - Clique em "Merge pull request"
    - Clique em "Confirm merge"

7.4 - O GitHub vai fazer merge na main e a Vercel vai fazer
    deploy automático em produção.

7.5 - Acesse a URL de produção:
    https://recomeco-nu.vercel.app (ou a URL que você usa)

================================================================================
SE ALGO DER ERRADO:
================================================================================

- Se o Supabase não responder, verifique as variáveis de ambiente
- Se a API não carregar, verifique o console do navegador (F12)
- Se o deploy da Vercel falhar, olhe os logs em "Deployments" → selecionar deploy → "Logs"
- Para testar novamente, faça mudanças → commit → push → aguarde novo preview

================================================================================
DESFAZER MUDANÇAS (SE PRECISAR):
================================================================================

  git checkout main
